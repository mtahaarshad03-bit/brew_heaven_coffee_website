Illustrations are generated by js/main.js (art()). To use real photos: save JPGs here named after the slot (esp.jpg, fw.jpg, col.jpg, hcl.jpg, cb.jpg, bag.jpg, cafe.jpg, gallery-1.jpg ... gallery-12.jpg; product names match the ids in js/main.js), then add the same names (without .jpg) to the PHOTOS array in js/main.js. Missing names keep the illustration.
